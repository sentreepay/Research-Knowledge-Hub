# Network Slicing & Resource Allocation

## 主題簡介

網路切片讓同一個實體網路支援具有不同服務需求的虛擬網路。資源分配研究需處理使用者請求動態到達、服務優先順序不同，以及資源使用的長期限制。本主題目前以 RAN 切片中的線上資源分配為核心。
