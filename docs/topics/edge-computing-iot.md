# Edge Computing & IoT Offloading

## 主題簡介

整理物聯網、邊緣與雲端協同運算，以及 IoT 任務卸載相關研究。主題關注如何依任務、網路及設備條件分配工作，並在延遲、能源消耗、資源使用率及服務需求之間取捨。
